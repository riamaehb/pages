# Data Preparation and Analysis — interactive training website

A static, self-contained learner site for the six-module Naga City LGU Google Sheets training.

## Open locally
Open `index.html` in a modern browser. All training files are in `downloads/`. No build or server is needed.

## Publish to GitHub Pages
Create a GitHub repository (for example `naga-training`), upload the contents of this folder to the repository root, then enable GitHub Pages from **Settings → Pages → Deploy from a branch → main / root**. The site will be available at your repository's Pages URL.

## Features
- Six self-paced modules with guided instructions and verification checks
- Google Sheets formula blocks with copy buttons
- Knowledge checks and explanations
- Completion tracking in browser localStorage
- Downloadable practice datasets and answer keys
- Mobile navigation
- Responsive and print-friendly

The website provides instructional guidance; learners perform the exercises in Google Sheets. The optional monthly update was not live-tested. All applicant records are synthetic.
